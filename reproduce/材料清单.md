# 复现材料与来源

默认公开样例使用仓库随附首帧，不需要本地Word报告、官方模板、手工导出的图片、旧工程环境或历史生成结果。模型权重和赛事统一基础运行时仍须由评测环境提供；仅有Git源码不能替代这些基础条件。

| 材料 | 获取位置 | 默认运行是否额外提供本地文件 |
| --- | --- | --- |
| 集成脚本及新增适配源码 | 本仓库与`source-lock.json`锁定的公开子模块；`prepare_sources.sh`初始化必需头文件子模块 | 否 |
| 统一首帧 | `assets/competition-first-frame.png`；字节数与SHA256由`assets/competition-inputs.json`固定 | 否，直接随git clone获得 |
| 固定提示词 | 脚本内默认`A dog falls asleep`，输入清单中也有记录 | 否 |
| 73个Python wheel及传递依赖 | 本仓库Release `offline-runtime-20261114`，`fetch_dependencies.py`自动下载、校验并解包至`inputs/wheelhouse` | 否；首次需联网下载，再传入离线节点 |
| 完整厂商Triton | 同一Release，解包至`inputs/vendor-triton`；保留共享库和版本元数据，逐文件校验 | 否 |
| xmake 3.1.2完整工具树 | 同一Release，解包至`inputs/vendor-xmake`；逐文件校验 | 否；如赛事基础镜像不同，可显式指定兼容的完整xmake安装树 |
| 官方参考及来源JSON | 验证入口调用未修改官方`--legacy`入口重新生成 | 否；仅显式指定外部参考时才需要成对提供REFERENCE_VIDEO和REFERENCE_PROVENANCE |
| 参赛输出、日志及计时 | 当前工程现场生成于`outputs/offline-validation` | 否，不读取Release中的历史结果参与推理或比较 |
| MiniMax-H3 Base FL2VA Diffusers权重 | 赛事统一提供，通过`MODEL_PATH`指定；原始模型项目为`MiniMaxAI/MiniMax-H3` | **是，赛事模型输入**；不随工程重新发布144 GB权重 |
| Linux x86_64、CPython 3.11、厂商Torch、DTK、GCC、驱动及系统库 | 赛事统一基础环境，按报告显式配置路径 | **是，基础环境**；不是参赛队电脑上的私有材料 |

公开首帧SHA256为`b97c3487ca35da0c803fba3787cf2b7f936d3d4595548ae5b7b576c19934be54`，与已完整验证的视频输入完全相同。首次拉取后运行`python scripts/check_inputs.py`即可校验，全部正式运行入口默认指向该文件；显式参数仍可覆盖默认值，以支持赛方提供的其他输入。

模型应包含`model_index.json`及text_encoder、transformer、vae、audio_vae、scheduler、audio_scheduler组件。`check_inputs.py --model-path "$MODEL_PATH"`提前检查配置、分片索引、权重文件是否齐全以及是否误放了Git LFS指针，不替代官方权重哈希核验，也不修改任何权重。

基础环境要求为单节点独占8张海光gfx936、每卡约64 GiB、128 CPU及486G主机内存的已验证配置；Linux glibc至少2.28，CPython 3.11含pip、venv和开发头文件，厂商Torch `2.9.0+das.opt1.dtk2604`、DTK 26.04、GCC 11.4.0和binutils。xmake需要基础系统的libatomic、readline 7、ncurses 6、tinfo 6及libstdc++。这些由赛事基础镜像提供，具体路径允许替换。

`dependencies/sgcup-installed-wheels.json`、`sgcup-vendor-manifest.json`及历史evidence中的绝对目录仅记录先前测试来源，运行脚本不读取其target字段。当前安装依据`offline-lock.json`、`runtime-lock.json`与`artifacts.json`，不会访问那些历史目录。

此前从DOCX提取首帧的步骤已移除。旧`reproduce/run_offline.sh`现转发到当前完整验证入口，不再要求旧版SOURCE_ARCHIVE、SGCUP_DEPENDENCY_PYTHONPATH、COMPETITION_TRITON_SOURCE或外部参考视频。`prepare_compiler_dependency.py`如被单独使用，默认也读取Release随附Triton。
